# Архівування та видалення класів

У розділі **Мої класи** є вкладки **Активні** та **Архів**. Дії доступні вчителю на картці класу й на сторінці самого класу. Інший учитель, учень або адміністратор, який не є власником цього класу, не може виконати ці дії.

- **Архівувати** прибирає клас і його призначення з активного списку та головного огляду. Учні, запрошення, звіти, оцінки, коментарі й попередні спроби зберігаються.
- **Відновити клас** у вкладці **Архів** повертає клас до роботи. Коди приєднання та склад учнів не змінюються. Призупинені й вибулі учні зберігають свій статус.
- **Видалити** показується лише для порожнього класу, в якому немає жодного учня (включно з вибулими), запрошення або призначення. Потрібне підтвердження у вікні; скасування нічого не змінює. Видалення остаточне. Сервер повторно перевіряє порожність у транзакції, тому застаріла сторінка не дозволить видалити нові дані.

В архівному класі учень може переглядати збережений звіт, завантажувати PDF і друкувати. Редагування та здавання заморожені. Нові приєднання за спільним чи особистим кодом, реєстрація з кодом цього класу, імпорт учнів, надсилання запрошень, зміни списку та нові призначення блокуються до відновлення. Уже прийнята поштовою службою розсилка може завершитися; її код не відкриє архівний клас.

Учитель зберігає доступ до звітів, перевірки, журналу оцінок, CSV та навчального поступу. Архівування не видаляє дані навчального журналу; звичайний строк зберігання навчальних подій продовжує діяти.

## Оновлення

Збережіть `.env` і зробіть резервну копію бази за інструкцією в README. Зупиніть сервер через Ctrl+C. У папці з `package.json` після оновлення файлів виконайте:

```powershell
npm ci
npm run db:generate
docker compose up -d db
npm run db:migrate
npm run dev
```

Нова міграція `202610290001_class_archive` додає необов’язкове поле `Classroom.archivedAt` та індекс. Усі наявні класи залишаються активними. Старі міграції не змінюються; скидання чи повторне наповнення бази не потрібне.

## Перевірка

`tests/e2e/classroom-lifecycle.spec.ts` перевіряє архів/відновлення, незмінність звітів та оцінок, перегляд учнем, мобільний інтерфейс, блокування редагування й кодів архівного класу, права власника, підтвердження видалення, захист класів з даними та одночасне приєднання/видалення. Тести запускаються тільки в окремій базі з назвою, що закінчується на `_test`.
