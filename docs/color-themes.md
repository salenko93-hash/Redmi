# Кольорові теми ФізЛаб

Є п’ять світлих палітр: Лісова, Океан, Лаванда, Сонячна та Троянда. Вони змінюють фон, текст, основні кнопки, навігацію, форми, панелі, фокус клавіатури та декоративні елементи. Кольори матеріалів, рідин, приладів і сил у SVG-дослідах не перефарбовуються.

- До входу перемикач «Кольорова тема» розташований біля форми входу/реєстрації.
- Після входу відкрийте меню профілю вгорі праворуч для швидкого перемикання.
- У «Мій обліковий запис» є великі картки-приклади всіх п’яти палітр.

Вибір зберігається на рік у cookie `fizlab-theme` для цього сайту в цьому браузері й на цьому пристрої. Він не змінює вигляд у інших учителів чи учнів. Це налаштування оформлення, окреме від сесії входу. На HTTPS cookie має прапорець Secure; локальний HTTP також підтримується. Якщо браузер не дозволив зберегти вибір, тема застосовується до відкритої сторінки й показується підказка.

Кореневий layout читає дозволену назву теми на сервері та передає ту саму тему провайдеру клієнта. Це дає узгоджений HTML після перезавантаження без підміни теми на старті. Невідомі значення замінюються лісовою палітрою. Зміна теми не перезавантажує сторінку, не очищує форму й не скидає параметри, паузу або результати досліду.

Палітри визначені в `app/themes.css`, список назв і мініатюр — у `lib/themes.ts`. Спільні компоненти використовують CSS-змінні; для обладнання не застосовуються кольорові фільтри. Модульні перевірки контролюють контраст звичайного тексту й кнопок від 4,5:1 та контурів фокуса від 3:1 для всіх п’яти палітр.

Перевірки: 78 модульних тестів і всі 34 браузерні сценарії, успішні перевірка типів і production-збірка. Окремо перевірено всі палітри, збереження cookie, серверний HTML і відображення без JavaScript, невідому назву теми, відсутність помилок гідратації, мобільну ширину, збереження введеної пошти та незмінний SVG призупиненого досліду після зміни теми.
