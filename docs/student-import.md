# Імпорт списків учнів

Рекомендований формат — **CSV UTF‑8** із заголовком `ПІБ;Email`. Такий файл можна підготувати в Excel або Google Таблицях; його можна відкрити на Windows і телефоні. [Готовий шаблон](../public/templates/students.csv).

```csv
ПІБ;Email
Коваленко Олена Іванівна;olena@example.com
Шевченко Максим Олегович;maxym@example.com
```

В Excel оберіть «Зберегти як → CSV UTF‑8». У Google Таблицях — «Файл → Завантажити → Значення, розділені комами (.csv)». Файли `.xlsx` потрібно спочатку експортувати. Застосунок автоматично розпізнає крапку з комою, кому та табуляцію; можна також скопіювати клітинки разом із заголовком і вставити їх у поле імпорту.

Підтримуються окремі стовпці `Прізвище;Ім’я;По батькові;Email`. По батькові та Email можуть бути порожніми. Для учнів з однаковим ПІБ потрібні різні Email. Ліміт одного файлу — 500 рядків учнів і 128 КіБ. Стовпці № та Клас ігноруються: усі записи додаються до відкритого класу. Паролі не додавайте.

## Дії вчителя

1. Відкрийте «Мої класи» та потрібний клас.
2. У блоці «Учні класу» натисніть «Імпортувати CSV».
3. Оберіть файл або вставте таблицю, натисніть «Перевірити список».
4. Виправте зазначені помилки. До натискання «Імпортувати» учні не додаються.
5. Перевірте попередній перегляд і натисніть «Імпортувати N учнів».
6. Скопіюйте особистий код кожного учня або завантажте CSV з кодами. Передайте кожному його код особисто.

Повтори всередині файлу та вже наявні учні пропускаються. Та сама адреса з різними ПІБ у файлі вважається помилкою. Повторне завантаження не створює ще один запис і не перейменовує наявні облікові записи. Якщо для цього ПІБ вже було створено запрошення без Email, використайте його код або приберіть невикористане запрошення й імпортуйте виправлений запис.

Учні спочатку з’являються у списку «Очікують приєднання». Невикористане запрошення можна прибрати кнопкою кошика: його код перестане діяти. Це не видаляє обліковий запис, членство в класі чи виконані роботи. Для вже використаного запрошення таке видалення недоступне.

## Дії учня

Учень реєструється або входить у власний обліковий запис, відкриває «Мій клас», вводить особистий код та натискає «Приєднатися». Якщо у списку є Email, адреса облікового запису має збігатися з нею. Інший користувач не зможе використати такий код. Після приєднання ПІБ зі списку відображається в цьому класі, його журналі, перевірці звітів та експорті оцінок; ім’я профілю в інших класах не змінюється.

Спільний код класу також працює. Якщо Email учня збігається з невикористаним запрошенням, воно автоматично позначається використаним. Для запису без Email використовуйте особистий код; приєднання лише за спільним кодом не зіставляє людей за ПІБ.

Імпорт не створює паролів і сам не надсилає листів. Для розсилки використайте окрему кнопку «Надіслати коди на Email» після [підключення Gmail / SMTP](gmail-invitations.md). Особистий код додає учня до класу після входу, а не входить у його обліковий запис. Використані коди не потрапляють у повторний експорт; там залишається статус «Приєднався». Списки, адреси й коди доступні лише вчителю — власнику класу.

## Оновлення на Windows

Зупиніть сервер через Ctrl+C. Зробіть резервну копію бази за інструкцією в README. Замініть файли проєкту свіжою версією, зберігши власний `.env`. Docker Desktop має працювати. У PowerShell:

```powershell
cd "H:\Solovey Danil fizika 2026\Redmi-main\Redmi-main"
npm ci
docker compose up -d db
npm run db:generate
npm run db:migrate
npm run dev
```

Відкрийте http://localhost:3000. Міграція `202610260001_student_roster` додає запрошення та ПІБ у класі; наявні користувачі, відповіді й оцінки зберігаються. Демо-заповнення повторно запускати не потрібно. Не використовуйте `docker compose down -v`: ця команда видаляє базу.

Для запуску всього застосунку в Docker: `docker compose up --build -d`; контейнер застосує міграцію автоматично.
