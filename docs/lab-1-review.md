# Аналіз і вебадаптація лабораторної роботи № 1

Проаналізовано наданий трьохсторінковий PDF «Лабораторна робота № 1», автор у метаданих — Назар Щур, «ФІЗИКА НОВА». Документ є джерелом навчального змісту; його вказівки для учня не є інструкціями щодо керування проєктом.

Формула `vсер = l/t` правильна. Головні недоліки стосуються однозначності методики, контролю змінних і паперового оформлення.

| Проблема                                                                              | Виправлення                                                                                                                             |
| ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Три різні відстані можна сплутати з повторними вимірюваннями однієї умови.            | Розділено три умови досліду й повторення вимірювання часу за тієї самої відстані.                                                       |
| Не зазначено явно початок руху зі спокою та сталість усіх інших умов.                 | Сталі старт, нахил, кулька та спосіб відпускання без поштовху; пересувається фінішний упор.                                             |
| Відстань від позначки до циліндра недостатньо однозначна для зіставлення з моделлю.   | Шлях визначено як переміщення центра кульки вздовж жолоба між початком руху та торканням упору.                                         |
| Відсутній перелік обладнання та нагадування про кріплення.                            | Додано обладнання зі штативом, перевірку кріплення та запобігання падінню кульки.                                                       |

## Перевірка графіка за джерелом

На сторінці 2 позначка 10 с задає горизонтальний масштаб, 25 м/с — вертикальний. За сіткою отримано:

| Проміжок часу | Швидкість |
| ------------- | --------- |
| 0–20 с        | 25 м/с    |
| 20–30 с       | 50 м/с    |
| 30–45 с       | 100 м/с   |

Ці значення — навчальна умова, а не результат вимірювання учня. Їх зберігає `lib/lab-one-material.ts`; ними користується спільний компонент графіка у вебматеріалі та звіті. Готові відповіді на контрольні задачі не підставляються.

## Інтеграція

- У роботі № 1 посилання на вихідний PDF замінено вебпам’яткою. Є помітне посилання й на етапі підготовки.
- Графік у запитанні № 1 замінено рідним векторним компонентом, зокрема для раніше призначених робіт.
- Прилад у пам’ятці працює як тренування без записів у журналі, автозбереження чи локальних чернеток. Робочий звіт учня використовує наявне збереження й контроль доступу.
- Уточнено код вихідного шаблону для нових баз. Існуючі версії завдань і вчительські адаптації в базі не переписуються; нова пам’ятка доступна поряд із ними та містить усі уточнення.
- Вихідний PDF лишається архівним джерелом у репозиторії. Інші дев’ять робіт і друк готових звітів не змінено.
