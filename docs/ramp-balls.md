# Кульки у віртуальному жолобі · робота № 1

Доступні дві суцільні однорідні кульки: сталева та пластмасова з поліпропілену. Діаметр змінюється від 10 до 50 мм із кроком 1 мм. Нахил залишається ліворуч, шлях — праворуч; довжина шкали — 2 м, шлях — 0,2–2 м. Жолоб має сталий технічний запас після шкали для встановлення упору.

Після зміни матеріалу чи діаметра одразу оновлюються вигляд, розмір кульки, її маса та густина. За незмінного діаметра сталева кулька важча: модельні густини — 7800 кг/м³ для сталі та 900 кг/м³ для поліпропілену. Це представницькі навчальні значення; густина інших пластмас може відрізнятися.

Маса обчислюється у SI:

```text
V = π·d³/6
m = ρ·V
```

У формулах діаметр задається в метрах. Прилад показує діаметр у міліметрах, масу — у грамах. Наприклад, за 20 мм сталева кулька має масу близько 32,67 г, пластмасова — 3,77 г. Подвоєння діаметра за тієї самої густини дає восьмикратну масу.

## Рух і рисунок

Є два режими кочення суцільної кульки без проковзування. Ідеальний режим v1 зберігає рівняння:

```text
a = (5/7)·g·sin(α), g = 10 м/с²
t = √(2·l/a)
s(t) = a·t²/2
φ = s/r
```

В ідеальному режимі за однакових шляху й нахилу час не залежить від маси чи діаметра, оскільки вони скорочуються в рівнянні руху суцільної кулі. У цьому режимі опору немає. У режимі v2 «У повітрі», який використовується для нового запуску за замовчуванням, додано квадратичний опір зі сталим коефіцієнтом сфери. Деформації, опір коченню, особливості профілю жолоба, підйомна сила повітря та удар об упор не моделюються. Вигляд приладу став докладнішим, а фізична модель залишається явно описаною навчальною ідеалізацією.

Для режиму «У повітрі» використано навчальне наближення нерухомого повітря поблизу кімнатної температури:

```text
ρпов = 1,2 кг/м³; Cd = 0,47; S = πd²/4
k = ½ρпов·Cd·S; b = k/(1,4m)
dv/dt = a₀ − bv²; a₀ = (5/7)g·sin(α)
x(t) = ln(cosh(√(a₀b)·t))/b
t(L) = asinh(√expm1(2bL))/√(a₀b)
```

Множник 1,4 враховує обертальну інерцію суцільної кулі `I = 2mR²/5`. Рівняння розв’язано аналітично зі стійкими формулами поблизу нуля; швидкість і положення відповідають тому самому часові. За однакового діаметра опір при заданій швидкості однаковий, проте його вплив на легшу пластмасову кульку більший. Різниця часів невелика, без штучного множника; час моделі відображається до тисячної секунди. Додаткові цифри не характеризують точність реального секундоміра. Сталий Cd — наближення, не повна аеродинамічна модель.

Мітки на кульці обертаються відповідно до фізичного кута кочення: менша кулька робить більше обертів на тому самому шляху. Саму кульку на основній схемі збільшено у 4 рази для видимості, зі спільним масштабом для всіх діаметрів і матеріалів. Це явно підписано; шкала шляху залишається 2 м. Положення упору враховує показаний радіус, тому кулька торкається його у фінальній позиції.

Анімація жолоба використовує розрахований час, без мінімального порога в одну секунду для коротких шляхів. Під час руху параметри заблоковані. Пауза відкриває керування; зміна будь-якого параметра скидає попередній запуск і покази часу. Зменшені анімації підтримуються.

Для трьох рядків основного звіту зберігайте режим опору, матеріал, діаметр і нахил сталими та змінюйте лише шлях. Порівняння матеріалів і діаметрів доступне як окреме творче дослідження.

## Збереження й оновлення

Нові перенесення зберігають режим опору, матеріал і діаметр разом зі шляхом, нахилом та показами часу. Повітряний режим має `modelVersion = 2`, ідеальний — `modelVersion = 1`. Сервер перевіряє відповідність версії, параметрів і результату; зміна тега версії або умов без перерахунку відхиляється. Моделі робіт № 2–10 залишаються v1. Сервер перевіряє допустимі межі й відповідність показів моделі. Маса обчислюється з діаметра й густини; незалежно задавати її для суцільної кульки з вибраного матеріалу не можна.

Раніше збережені записи моделі v1 із параметрами лише «шлях» та «нахил» перевіряються за тим самим рівнянням і зберігають ті самі покази. Їм не приписуються нові історичні властивості кульки: матеріал і діаметр у старій історії не показуються. При відновленні приладу з таких старих записів використовуються початкові 20 мм і сталь, а режим залишається ідеальним. Старі записи з матеріалом і діаметром без прапорця опору також лишаються ідеальними, не отримують нових історичних умов і проходять перевірку з колишніми показами. Нові записи містять обидва нові параметри.

Уточнено творче завдання вебпам’ятки. Для наявних завдань оновлюється показ лише точного відомого стандартного тексту, де раніше було сказано, що матеріал не змінюється. Авторські формулювання вчителя та записи у базі зберігаються.

Міграція бази не потрібна. На Windows зупиніть сервер Ctrl+C, замініть файли проєкту оновленою версією, зберігши `.env`, і запустіть:

```powershell
cd "H:\Solovey Danil fizika 2026\Redmi-main\Redmi-main"
npm ci
npm run dev
```

Якщо оновлюєте старішу версію без попередніх змін адмінки чи розсилки, спершу виконайте загальне оновлення бази за README. Для повністю контейнерного запуску використайте `docker compose up --build -d`.
