# Кульки у віртуальному жолобі · робота № 1

Доступні дві суцільні однорідні кульки: сталева та пластмасова з поліпропілену. Діаметр змінюється від 10 до 50 мм із кроком 1 мм. Нахил залишається ліворуч, шлях — праворуч; довжина шкали — 2 м, шлях — 0,2–2 м. Жолоб має сталий технічний запас після шкали для встановлення упору.

Після зміни матеріалу чи діаметра одразу оновлюються вигляд, розмір кульки, її маса та густина. За незмінного діаметра сталева кулька важча: модельні густини — 7800 кг/м³ для сталі та 900 кг/м³ для поліпропілену. Це представницькі навчальні значення; густина інших пластмас може відрізнятися.

Маса обчислюється у SI:

```text
V = π·d³/6
m = ρ·V
```

У формулах діаметр задається в метрах. Прилад показує діаметр у міліметрах, масу — у грамах. Наприклад, за 20 мм сталева кулька має масу близько 32,67 г, пластмасова — 3,77 г. Подвоєння діаметра за тієї самої густини дає восьмикратну масу.

## Рух і рисунок

Збережено модель кочення суцільної кульки без проковзування:

```text
a = (5/7)·g·sin(α), g = 10 м/с²
t = √(2·l/a)
s(t) = a·t²/2
φ = s/r
```

За однакових шляху й нахилу час не залежить від маси чи діаметра, оскільки вони скорочуються в рівнянні руху суцільної кулі. Опір повітря, деформації, особливості профілю жолоба та удар об упор окремо не моделюються. Вигляд приладу став докладнішим, а фізична модель залишається явно описаною навчальною ідеалізацією.

Мітки на кульці обертаються відповідно до фізичного кута кочення: менша кулька робить більше обертів на тому самому шляху. Саму кульку на основній схемі збільшено у 4 рази для видимості, зі спільним масштабом для всіх діаметрів і матеріалів. Це явно підписано; шкала шляху залишається 2 м. Положення упору враховує показаний радіус, тому кулька торкається його у фінальній позиції.

Під час руху параметри заблоковані. Пауза відкриває керування; зміна будь-якого параметра скидає попередній запуск і покази часу. Зменшені анімації підтримуються.

Для трьох рядків основного звіту зберігайте матеріал, діаметр і нахил сталими та змінюйте лише шлях. Порівняння матеріалів і діаметрів доступне як окреме творче дослідження.

## Збереження й оновлення

Нові перенесення зберігають матеріал і діаметр разом зі шляхом, нахилом та показами часу. Сервер перевіряє допустимі межі й відповідність показів моделі. Маса обчислюється з діаметра й густини; незалежно задавати її для суцільної кульки з вибраного матеріалу не можна.

Раніше збережені записи моделі v1 із параметрами лише «шлях» та «нахил» перевіряються за тим самим рівнянням і зберігають ті самі покази. Їм не приписуються нові історичні властивості кульки: матеріал і діаметр у старій історії не показуються. При відновленні приладу використовуються початкові 20 мм і сталь для нового запуску. Нові записи містять обидва нові параметри.

Уточнено творче завдання вебпам’ятки. Для наявних завдань оновлюється показ лише точного відомого стандартного тексту, де раніше було сказано, що матеріал не змінюється. Авторські формулювання вчителя та записи у базі зберігаються.

Міграція бази не потрібна. На Windows зупиніть сервер Ctrl+C, замініть файли проєкту оновленою версією, зберігши `.env`, і запустіть:

```powershell
cd "H:\Solovey Danil fizika 2026\Redmi-main\Redmi-main"
npm ci
npm run dev
```

Якщо оновлюєте старішу версію без попередніх змін адмінки чи розсилки, спершу виконайте загальне оновлення бази за README. Для повністю контейнерного запуску використайте `docker compose up --build -d`.
