# ФізЛаб 1.1.0

Підсумковий випуск від 30 жовтня 2026 року об’єднує погоджені зміни в одному повному проєкті. Початкові версії коду збережені в історії Git та окремих попередніх гілках; старі версії навчальних робіт і їхні призначення залишаються в базі.

## Склад випуску

- Десять лабораторних робіт із віртуальними приладами, вебпам’ятками й адаптивним інтерфейсом.
- Постійна верхня навігація; керування приладом праворуч; параметри й таблиці під установкою.
- Ручний секундомір у №1–3 керує рухом у масштабі 1×. Час учень вводить самостійно; перенесення показів його не перезаписує.
- У першій роботі стіл і жолоб адаптуються до ширини поля, таблиця розташована одразу після параметрів і перенесення показів. Великий дубльований блок характеристик кульки прибрано, замість картки маршруту показано формулу швидкості з одиницями.
- Окрема версія першої роботи з проблемним запитанням, прогнозом, планом, аналізом доказів, повторними вимірюваннями за можливості та переглядом думки. Учитель оцінює обґрунтування за чотирма критеріями.
- На сторінці першої роботи прибрано редактор навчального тексту та службове пояснення з посиланням на попередню версію.
- Окремі кнопки збереження PDF і друку повного звіту, включно з новими відповідями першої роботи.
- Реєстрація за ролями, окремі запрошення вчителів та учнів, адміністрування доступів, класи, архівування, оцінювання та повернення робіт на доопрацювання.
- Серверне автозбереження, локальні чернетки, захист від непомітного перезапису між пристроями, історія спроб.
- Кольорові теми, калькулятор і таблиця густин. Добровільний журнал навчального поступу залишається окремою функцією.

## Встановлення

Почніть із [START-HERE.md](../START-HERE.md). Архів містить код, зафіксовані версії залежностей у `package-lock.json`, міграції, `.env.example`, матеріали робіт і документацію. Локальні `.env`, `node_modules`, `.next` та резервні копії бази до архіву не входять. Залежності встановлює `npm ci`, клієнт бази створює `npm run db:generate`.

Випуск не містить даних із вашого ПК. Для оновлення наявного встановлення збережіть його `.env`, папку проєкту та базу. Для додавання нового шаблону першої роботи потрібен звичайний `npm run db:seed`, без прапорця `--demo`.

Зміни бази виконуються чинним набором міграцій через `npm run db:migrate`; SQL уже застосованих міграцій не переписано. Додавання навчальної методики першої роботи не потребує нових колонок.

## Перевірка випуску

- 89 модульних перевірок: формули, моделі, валідація відповідей, сумісність версій, звіти та інші правила застосунку.
- 20 вибраних браузерних сценаріїв: реєстрація за ролями, доступи, класи, усі десять приладів на мобільному екрані, ручний час, навчальна методика першої роботи, чернетки, конфлікти між пристроями, здавання, оцінювання, PDF та друк.
- Перевірка TypeScript і збірка застосунку.

Браузерні сценарії перевірені групами на окремій тестовій базі. Під час великої спільної серії багато входів одним демонстраційним обліковим записом досягають чинного ліміту авторизації; захист у застосунку не послаблювався. Для повторної перевірки окремої групи використовуйте, наприклад, `npm run test:e2e -- tests/e2e/workflow.spec.ts`. Тестова база очищується командою перевірки; робочу базу для тестів використовувати не можна.
