ОНОВЛЕННЯ ФІЗЛАБ

Для вчителів: призупинення та відновлення доступу; остаточне видалення акаунта з бази після підтвердження. Класи та учнівські роботи передаються адміністратору. Після видалення та нового запрошення можна повторно зареєструвати ту саму пошту. Старі пароль і коди більше не діють. Раніше архівовані акаунти також можна остаточно видалити. Для учнів зберігається оборотне видалення зі списку класу. Додано повторне введення пароля при реєстрації та показ/приховування пароля.

Як оновити наявну встановлену версію:
1. Зупиніть застосунок Ctrl+C. Залиште Docker Desktop запущеним.
2. Зробіть резервну копію бази з папки старого проєкту:
   cmd /c "docker compose exec -T db pg_dump -U fizlab -d fizlab -Fc > fizlab-backup.dump"
   (Для Windows PowerShell використано cmd, щоб зберегти двійковий файл без перекодування.)
3. Розпакуйте архів у тимчасову папку. Скопіюйте вміст Redmi в НАЯВНУ папку проєкту із заміною файлів. Збережіть ваш .env, резервну копію та Docker volume. Не запускайте другу копію з нової папки: Compose може створити окрему порожню базу.
4. У терміналі в наявній папці проєкту виконайте:
   npm ci
   docker compose up -d db
   npm run db:generate
   npm run db:migrate
   npm run dev
5. Відкрийте http://localhost:3000 (або вашу адресу APP_URL).

Не виконуйте docker compose down -v. Нова міграція лише додає поля стану; учні, класи, роботи та оцінки залишаються.
Дії команди вчителів доступні адміністратору. Надання прав наявному активному вчителю:
   npm run admin:grant -- --email ваша-пошта

Якщо застосунок ще не встановлено, дотримуйтеся розділу «Локальний запуск» у README.md. При першому локальному встановленні можна додати демонстраційні дані через npm run db:seed -- --demo. Для оновлення наявних даних демо-заповнення не потрібне.

Перевірки цієї версії: 76 модульних і 4 браузерних тести керування доступом, адміністрування та реєстрації, збірка та TypeScript пройшли. Повний набір E2E не запускався.
