# ФізЛаб 1.1.0 — з чого почати

Це повний проєкт із погодженими змінами станом на 30 жовтня 2026 року. Окремі попередні пакети встановлювати не потрібно.

## Якщо застосунок уже працював на вашому ПК

1. Зупиніть його через **Ctrl+C** у вікні PowerShell.
2. Розпакуйте архів в окреме тимчасове місце. Скопіюйте **вміст папки з `package.json`** у вашу наявну папку проєкту. Не створюйте всередині неї ще одну вкладену папку.
3. Збережіть наявний **`.env`**. Не замінюйте його файлом прикладу. Для наявної бази залиште той самий `DATABASE_URL`.
4. Залиште назву та розташування поточної папки проєкту. Docker Compose використовує ім’я проєкту для пошуку тому бази; запуск із нової папки може під’єднати нову порожню базу. За наявності навчальних даних зробіть резервну копію за [інструкцією адміністратора](docs/admin.md).
5. Виконайте команди нижче. Міграції та звичайний `db:seed` зберігають наявні версії робіт і додають потрібні зміни.

## Підготовка та запуск у PowerShell

Потрібні **Node.js 24**, npm та запущений **Docker Desktop**. Для вашого поточного розташування:

```powershell
cd "H:\Solovey Danil fizika 2026\Redmi-main\Redmi-main"
Test-Path .\package.json
```

Має з’явитися **True**. Якщо папка інша, перейдіть саме до тієї, де лежить `package.json`. Команди npm потрібно виконувати звідти, а не з `C:\Windows\System32`.

Для нового встановлення створіть `.env` із прикладу; наявний файл ця команда не перезаписує:

```powershell
if (!(Test-Path .\.env)) { Copy-Item .\.env.example .\.env }
```

Для локального входу через цей комп’ютер значення `APP_URL` у `.env` має бути `http://localhost:3000`.

Виконайте по черзі. Якщо команда завершилася помилкою, спочатку усуньте її:

```powershell
docker compose up -d --wait db
npm ci
npm run db:generate
npm run db:migrate
npm run db:seed
npm run build
npm start
```

Після повідомлення про готовність відкрийте **http://localhost:3000**. Залиште PowerShell відкритим. Після оновлення файлів натисніть **Ctrl+F5** у браузері.

Це запуск зібраного застосунку. Для подальших змін коду зупиніть його через Ctrl+C та запустіть `npm run dev`. Після завершення змін знову виконайте `npm run build` і `npm start`.

При наступному запуску без оновлення файлів достатньо:

```powershell
cd "H:\Solovey Danil fizika 2026\Redmi-main\Redmi-main"
docker compose up -d --wait db
npm start
```

## Нова перша лабораторна

У бібліотеці відкрийте **«Середня швидкість руху · дослідження з доказами»**. Для перевірки є кнопка **«Спробувати як учень»**. Для роботи учнів призначте класу цю версію. Уже призначені старі роботи автоматично не змінюються.

Учень записує прогноз і план, зіставляє числові докази, перевіряє сумніви та пояснює перегляд своєї думки. Великого дубльованого блоку характеристик кульки й обведеного редактора на сторінці першої роботи немає. Таблиця стоїть після параметрів, праворуч — формула середньої швидкості. [Докладніше про методику](docs/lab-1-inquiry.md).

## Якщо це зовсім нова база

Звичайний `npm run db:seed` створює шаблони, без демонстраційних користувачів. Для власного вчительського облікового запису створіть запрошення:

```powershell
npm run teacher:invite
```

Відкрийте реєстрацію, оберіть роль учителя та введіть отриманий код. Після створення облікового запису надайте йому права адміністратора:

```powershell
npm run admin:grant -- --email "ваша_адреса@example.com"
```

У вже налаштованому застосунку використовуйте ваші наявні облікові записи.
