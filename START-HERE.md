# ФізЛаб 1.2.0 — запуск та оновлення

Перший етап методичного оновлення: роботи **№1, №9, №10**. [Що змінилося та як перевірити](docs/methodology-stage-one.md). Попередній варіант 1.1.0 збережено окремим випуском на GitHub. На комп’ютері оновлення потрібно встановити самостійно.

## Оновлення вашого наявного проєкту на Windows

Ваше актуальне розташування: **`F:\Fisika 7 class\Fisika2026`**. Потрібні Node.js 24, npm і запущений Docker Desktop.

1. Зупиніть сервер цього проєкту через **Ctrl+C** у його вікні термінала. Збережіть копію папки проєкту та [резервну копію бази](docs/admin.md).
2. Розпакуйте новий архів в окрему тимчасову папку. Скопіюйте **вміст папки з `package.json`** у `F:\Fisika 7 class\Fisika2026`. Не додавайте ще один рівень вкладеності.
3. Збережіть свій **`.env`** та наявний `DATABASE_URL`. Архів не містить ваших облікових записів і бази — вони залишаються у вашому PostgreSQL.
4. У `.env` установіть **`APP_URL="http://localhost:3002"`** для запуску на цьому ПК. Порт 3000 у вашій конфігурації займає інший застосунок, CNL Management.

Перевірте папку в PowerShell:

```powershell
cd "F:\Fisika 7 class\Fisika2026"
Test-Path .\package.json
```

Має бути **True**. Команди npm виконуйте саме в цій папці.

У вашій попередній конфігурації база зберігалася в контейнері **`redmi-main-db-1`** на `127.0.0.1:5432`. Використовуйте його, щоб залишитися на тій самій базі:

```powershell
docker start redmi-main-db-1
```

Якщо контейнер має іншу назву, перевірте `docker ps -a` та свій `DATABASE_URL`, перш ніж створювати нову базу. Запуск `docker compose up db` з нової папки може створити інший том і порожню базу. Наявний том видаляти не потрібно.

Далі виконуйте по черзі; якщо команда завершилася помилкою, спочатку усуньте її:

```powershell
npm ci
npm run db:generate
npm run db:migrate
npm run db:seed
npm run build
npm start -- --port 3002
```

Відкрийте **http://localhost:3002**, залиште термінал відкритим. Виконайте **Ctrl+F5** у браузері після оновлення. Звичайний `db:seed` додає нові версії шаблонів; учнів, класи, призначення, відповіді та оцінки не перезаписує. Прапорець `--demo` для вашої наявної бази не потрібен.

## Для подальшої зміни коду

Зупиніть сервер цього проєкту через Ctrl+C та запустіть:

```powershell
cd "F:\Fisika 7 class\Fisika2026"
npm run dev -- --port 3002
```

Не запускайте одночасно два `next dev` з тієї самої папки: інший порт не знімає блокування. Після завершення змін перевірте `npm run typecheck`, `npm test` та `npm run build`.

Наступного разу без зміни файлів для зібраного застосунку достатньо:

```powershell
cd "F:\Fisika 7 class\Fisika2026"
docker start redmi-main-db-1
npm start -- --port 3002
```

## Як відкрити оновлені роботи

Увійдіть учителем і відкрийте роботи №1, №9 і №10 в бібліотеці. Для швидкого ознайомлення натисніть **«Спробувати як учень»**: у цьому режимі відповіді не зберігаються. Для роботи учнів призначте класу нові версії. Раніше призначені роботи автоматично не змінюються.

Для телефона `APP_URL` має збігатися з адресою, яку відкриваєте на телефоні, наприклад `http://<поточна-IP-адреса-ПК>:3002`. Після зміни `.env` перезапустіть сервер. Пристрої мають бути в одній мережі, а порт 3002 — доступним у приватній мережі Windows.

## Якщо це нове встановлення

Скористайтеся [загальною інструкцією](README.md#локальний-запуск), створіть `.env` із прикладу, налаштуйте окрему базу й вільний порт. Для першого вчителя є `npm run teacher:invite`, після реєстрації — `npm run admin:grant -- --email "ваша_адреса@example.com"`. У вже налаштованому застосунку використовуйте наявні облікові записи.
